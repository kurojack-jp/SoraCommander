# Sora Commander Config Builder

Ownerが `allowed-roots.txt`・`language.txt`・`tasks.json` を編集するオフラインの補助ツールです。
Windowsと、Tcl/Tkを含むPython 3.13を使います。標準ライブラリと同梱の本体検証モジュールで動きます。

Sora Commanderのフォルダで起動します。

```powershell
py -3.13 -B tools\scn_config_builder.py
```

1. **許可フォルダ**でフォルダを選んで追加します。既定は「読むだけ」です。
   選択した項目のモード変更・削除ができます。フルへの変更時には警告を確認します。
   設定保存をオフにするとcheckoutだけが既定になります。オンで空の一覧は不正です。
   検証欄に行番号と理由が表示されます。項目を変更してもコメント行は保持します。
2. **承認窓の言語**でWindowsに合わせる／English／日本語を選びます。
   未設定を選ぶと、既存の `language.txt` は削除候補になります。
3. **タスクプリセット**で既存項目またはnpm／pytestテンプレートを選びます。
   cwd・実行ファイル・説明・引数などを設定し、「フォームをJSONに反映」を押します。
   argvは1行1引数です。改行を含む引数や空文字1つだけの引数はJSON欄で直接編集します。
   JSONは編集に合わせて検証します。未反映のフォームがある間は保存できません。
   テンプレートは `cmd.exe /d /s /c` 形式の設定だけを作り、実行はしません。
   cwdがフルアクセスの範囲外なら警告します。設定保存をオフにすると `tasks.json` を削除します。
4. **確認と保存**で3ファイルの全文と追加・削除行数を確認します。
   読み取りの警告にチェックし、WRITE（書き込み）／DELETE（削除）の最終一覧を確認します。
   内容が変わると確認はやり直しになります。変更対象の既存ファイルは
   `*.bak-YYYYMMDD-HHMMSS` に退避し、バイト一致を確認してから1ファイルずつatomic置換します。
   同じ名前のバックアップがあれば停止し、上書きしません。
5. 保存後の本体起動時検証結果を確認します。反映にはBrokerとクライアントを手動で再起動してください。

**許可したフォルダ内のファイルは、承認窓なしでChatGPTから読まれます。**
秘密情報を含むフォルダは許可しないでください。読むだけの指定はファイル操作ツールの制限です。
承認したコマンドはOwnerの権限で動くため、そのフォルダへの書き込みを防ぐことはできません。
編集対象は `%USERPROFILE%\.config\sora-commander` の3ファイルと、そのバックアップ・一時ファイルです。
設定ディレクトリがなければ保存確認後に作成します。トンネルの鍵やYAMLにはアクセスしません。

右上の表示言語切替は `language.txt` と独立しています。本体の診断理由は英語で表示される場合があります。

## 読み取り専用の確認

```powershell
py -3.13 -B tools\scn_config_builder.py --check
```

各設定につき `[PASS]`（検証成功）／`[WARN]`（注意）／`[HOLD]`（停止）を1行で表示します。
終了コード0はHOLDなしです。WARNはcheckout既定の利用などを示します。
終了コード1はHOLDありです。ファイル・ディレクトリ・キャッシュ・画面は作成しません。
本体の起動時読み込みを使用し、リンクや通常ファイル以外の設定パスも拒否します。

## 失敗時と制限

- 保存中は他の設定エディターを閉じてください。読み込み後の外部変更は拒否します。
  Builder同士は排他的な一時ロックを使います。
- atomic置換は1ファイル単位です。3ファイル一括のトランザクションではありません。
  途中失敗時は保存済みファイルとバックアップを表示して停止し、`.config-builder.lock` と
  残った一時ファイルを保持します。ファイルを確認し、保存中のBuilderがないと確かめてから、
  ロックを手動で解決してください。自動ロールバック・削除再試行・承認再試行はありません。
  手動で整合を確認した後、画面を閉じて開き直してください。
  ロックの変化や削除失敗も保存停止として扱います。設定の一部がすでに保存されている場合があるため、
  表示された保存済みファイルを先に確認してください。
- 同じユーザー権限で動く別ソフトを隔離する機能はありません。保存後検証でも、
  悪意ある同時書き換えや、複数ファイルの電源断時の一貫性までは保証しません。
- 既存ファイルのUTF-8が壊れている場合やサイズ超過時は、内容の損失を避けるためGUIの読み込みを止めます。
  先に手動で修正してください。通常のテキストの誤りは、フォルダ項目の入れ替え、言語選択、JSON編集で直せます。
- 許可フォルダとタスクはUTF-8 BOMを受け付け、64 KiBまでです。言語は256バイトまでです。
  同じモード内の重複・包含は本体が許容し、フルと読むだけの間の重なりは拒否します。
  Builderは本体の検証ルールを緩めません。
- 実ファイルを使う保存テストと、GUI・日本語パスの実機受入は未実施です。
  メモリ上の検証・画面制御テストの成功は、Windowsでのファイル置換や実画面の受入を意味しません。

## オフライン配布物の組み立て

```powershell
py -3.13 -B tools\build_config_builder.py
```

`artifacts/config-builder/config-builder.zip` にツール、同じソースの本体検証モジュール、
ライセンス、両言語の説明書とクイックスタート、SHA-256付き一覧をまとめます。既存の出力フォルダは拒否します。
ZIP全体を専用フォルダに展開して起動してください。許可フォルダ設定がない場合、
**展開先のフォルダ**がBuilderでのcheckout既定になります。別のSora Commanderと使う際は、
許可フォルダを明示的に設定し、その本体でも検証してください。
公開・インストールは行いません。Config Builder とこのスクリプトは公開版のソースに含まれています。作ったZIPは手元に保存するだけで、ZIPを配布するには別にOwnerの公開判断が必要です。
